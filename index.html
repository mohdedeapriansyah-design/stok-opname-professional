Stok Opname

Memudahkan Komper Otomatis

Aplikasi ini dirancang untuk membantu proses Stock Opname dan rekonsiliasi data secara cepat. Pengguna dapat memasukkan template Komper, memilih banyak file hasil SO, kemudian engine membaca kode SAP dan QtyFix secara otomatis.

  • Template asli tidak ditimpa atau diubah.
  • Nilai desimal seperti 3.0 dinormalisasi menjadi 3.
  • File SO dapat lebih dari satu dan dapat memiliki banyak sheet.
  • Pencarian header dilakukan secara dinamis.
  • Hasil dapat di-preview dan di-download.
  • Berjalan responsif di web dan Android melalui PWA.
