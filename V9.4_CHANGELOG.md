# V9.4 — Automatic Header Detection

- Odoo optional.
- SAP optional.
- Keduanya tidak wajib tersedia bersamaan.
- Posisi kolom bebas.
- Header dicari pada 40 baris pertama setiap sheet.
- Qty alias: qtyFix, qty, quantity, qtySO, qtyOpname, hasilSO, stockQty, SOQty.
- Odoo alias: productOdooCode, odooCode, odooProductCode, kodeOdoo, odoo.
- SAP alias: productSapCode, sapCode, kodeSAP, sapProductCode, materialCode, material.
- Nama alias: productName, namaProduk, productDescription, description, nama.
- Pencocokan memakai key ODOO, SAP, lalu NAME.
- Tidak melakukan pemotongan/rekayasa nilai SAP.
- Setiap file/sheet dideteksi secara independen.
